First pre-release of ShowMesh Companion, for macOS 11 or later on Apple silicon and Intel.

The companion runs on the computer that runs Resolume Arena. It relaunches Arena when Arena is not running and supervision is armed, and it shows LTC timecode decoded from an audio input on that computer. It follows Show Night on a ShowMesh coordinator: supervision arms while a night is running and disarms when the night is inactive or stopped. If the coordinator stops answering during a night, the companion keeps the last state it saw and stays armed.

## Not verified yet

This build has passed unit tests and has not been run on real hardware. No Resolume relaunch, decoded LTC frame, or coordinator connection from a packaged build has been observed. `docs/BENCH-VERIFICATION.md` lists the checks still to run.

## Known limits

- The app is not signed or notarized. macOS blocks the first launch: open it once, then choose Open Anyway in System Settings, Privacy and Security.
- macOS asks for microphone access the first time LTC capture starts. Capture needs it.
- The companion does not report to the coordinator, so ShowMesh cannot show its state.
- The expected LTC frame rate is not compared with the show's configured rate.
- Open at login is saved but does nothing.
- There is no Windows build.
