Second pre-release of ShowMesh Companion, for macOS 11 or later on Apple silicon and Intel. It needs ShowMesh Core 0.4.0 or later on the coordinator.

On macOS the companion now finds Resolume Arena crash reports in `~/Library/Logs/DiagnosticReports` and sends each new one to the coordinator, so a crash on the render computer can be read with `showmeshctl companion-reports` without logging into it. Sending needs a coordinator address and a token for a coordinator principal with the `companion` role, entered in the new Coordinator token field. The Crash reports switch is on by default, and the tray and settings window show how many reports were sent, when the last one went, and the last problem.

## Not verified yet

This build has passed unit tests, and its upload code has sent reports to a coordinator running on a development machine. It has not run on the playout Mac, no real Arena crash report has been sent, and no packaged build has been tested. `docs/BENCH-VERIFICATION.md` lists the checks still to run, including R1 to R8 for crash reports.

## Known limits

- The app is not signed or notarized. macOS blocks the first launch: open it once, then choose Open Anyway in System Settings, Privacy and Security.
- macOS asks for microphone access the first time LTC capture starts. Capture needs it.
- Apart from crash reports, the companion does not report to the coordinator, so ShowMesh cannot show its state.
- Crash reports over 4 MB are not sent.
- The expected LTC frame rate is not compared with the show's configured rate.
- Open at login is saved but does nothing.
- There is no Windows build.
